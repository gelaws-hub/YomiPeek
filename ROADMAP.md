# Roadmap

## Phases 0–2

Foundation, functional offline term dictionary, Android text-selection integration and optional native floating lookup implemented. Acceptance evidence and remaining compatibility/performance limits are recorded in `docs/testing.md` and `docs/known-limitations.md`. Broader dictionary schemas, richer structured rendering, and representative real-device benchmarks remain follow-up work rather than implied universal compatibility.

## Next

1. Phase 3: portable backup/restore, real Google OAuth and Drive backup; local usage stays independent.
2. Phase 4: operation IDs, tombstones and concurrent multi-device merge simulations.
3. Phase 5: collections, notes, sentence mining and a tested study scheduler.
4. Phase 6: text reading, segmentation and tap-to-lookup.

See DEVELOPMENT.md for the full product specification; this implementation intentionally stays within phases 0–2.
